# Проверки версии 0.1.0-beta

Выполнено в Linux-среде, 25 ноября 2026 года:

- `go test -race ./...`: применение, повторное применение, восстановление, несколько поколений копий, отказ при повреждённой копии и обновлённом файле; распознавание точных DNS-имён, IPv4/IPv6-ответы, чтение SNI и отказ прокси для неподдерживаемого порта.
- `go vet ./...` и `GOOS=windows GOARCH=amd64 go vet ./...`.
- Сборки Windows x64 и Linux x86_64, без CGO.
- Запуск Windows-бинарника и просмотр окна через Wine. Это проверка запуска интерфейса, а не полноценная замена Windows-тестированию.
- Применение к изолированной копии реального Linux CLI версии 1.5.16. После патча команда `--version` выполняется. После отката SHA-256 совпадает с исходным файлом. Установленный клиент при этой проверке не изменялся.
- Установка готового Linux-пакета в изолированный домашний каталог, запуск меню и создание обоих ярлыков. Проверка состава архивов и SHA-256.
- Сетевой тест трёх целевых имён: установлено TCP-соединение и проверен TLS-сертификат каждого имени.

Не проверены на реальной Windows: UAC, установка и удаление службы, NRPT и запуск редактора с обычными правами. Не проверены вход в Google, ответ модели, голосовые сессии, поведение после реального автообновления Antigravity, все версии Desktop/IDE/расширения. Это причины маркировки beta.

## Проверка готового пакета на Windows

1. На Windows 10/11 x64 с установленным Antigravity полностью закройте клиент.
2. Запустите EXE, нажмите «Включить», проверьте результат в журнале.
3. В `services.msc` должна работать служба PrivetAntigravity. DNS-правила должны иметь метку `PrivetAntigravity-v1` только для трёх имён из TECHNICAL.md.
4. Запустите Antigravity кнопкой и отправьте сообщение модели.
5. Перезагрузите компьютер и повторите проверку.
6. Закройте клиент, выполните откат, убедитесь, что служба и правила удалены, а файлы восстановлены.

## Проверка готового пакета на Arch Linux

1. Выполните `./install.sh` без sudo в распакованной папке.
2. В меню выполните включение; для системных файлов подтвердите повышение прав.
3. Проверьте `systemctl --user status privetantigravity.service`.
4. Запустите Antigravity через ярлык и проверьте ответ модели.
5. Выполните откат, проверьте восстановление файла и отключение службы.
