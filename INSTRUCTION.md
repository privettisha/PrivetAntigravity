# Инструкция PrivetAntigravity

## Windows — первый запуск

1. Установите Antigravity. Сохраните открытые файлы и полностью выйдите из программы, включая значок в трее.
2. Распакуйте архив патчера в обычную папку.
3. Откройте `PrivetAntigravity.exe`. Подтвердите запрос Windows на права администратора: они нужны для службы и точечных DNS-правил.
4. Оставьте поле папки пустым для автоматического поиска. Для нестандартной установки нажмите «Выбрать…» и укажите исполняемый файл Antigravity.
5. Нажмите «Включить» и дождитесь результата. Ошибки отображаются в журнале.
6. Нажмите «Запустить Antigravity», войдите в Google и напишите модели простое сообщение.

После включения окно патчера можно закрыть: служба продолжит работать и запустится при следующем включении компьютера.

## Arch Linux — первый запуск

Распакуйте пакет и выполните в его папке:

```sh
./install.sh
```

Устанавливайте от обычного пользователя. Появятся два ярлыка:

- **PrivetAntigravity** — меню настройки.
- **PrivetAntigravity — запуск** — запуск редактора через локальную службу.

В меню выберите **1**. Если файлы находятся в `/opt` или другой системной папке, подтвердите запрос `pkexec` или введите пароль в обычном приглашении `sudo`. Помощник возвращает владельца резервных копий вашему пользователю.

Выберите **2**, войдите в Google и проверьте ответ модели. При нестандартной установке сначала укажите папку пунктом **4**. Для системного пакета обычно подходит `/opt/antigravity` или `/usr/share/antigravity`; выберите фактическую папку своего пакета.

Для работы нужны стандартный сеанс `systemd --user` и Antigravity. Готовый бинарник не требует установки Go, Python или дополнительных библиотек. `pkexec` необязателен: при его отсутствии используется `sudo`.

Если ярлыки пока не появились, запустите:

```sh
~/.local/bin/privetantigravity
```

## Что делают кнопки

- **Включить** — сохраняет оригиналы, применяет распознанные изменения и запускает службу.
- **Проверить** — проверяет сеть и сертификаты серверов. Это не проверка подписки или аккаунта.
- **Откатить** — выключает подключение и восстанавливает оригиналы подходящей версии.
- **Запустить Antigravity** — запускает клиент с настройками подключения.
- **Повторять патч после обновлений** — включает фоновую проверку файлов раз в 30 секунд.

В Linux этим действиям соответствуют пункты меню.

## Если не получилось

**Не найдена установка.** Укажите папку вручную. Для CLI выберите папку с `agy` или `agy.exe`. Поддерживается поиск бинарников в `.gemini/bin` и расширений Antigravity в VS Code.

**Не удалось записать файл.** Полностью закройте Antigravity. В Windows запускайте патчер с правами администратора. В Linux подтвердите запрос прав для системной папки. Затем повторите включение.

**Подходящая сигнатура не найдена.** Эта версия или компонент пока не поддерживается, либо уже изменён. Патчер оставляет такой файл без изменений. Архивы `app.asar`, неизвестные проверки и неизвестные архитектуры напрямую не редактируются; внешний бинарник в той же установке обрабатывается, если он поддерживается.

**Служба не запускается.** Посмотрите журнал. Локальные порты могли быть заняты другим приложением. Патчер использует `127.0.0.1:53147`; в Windows дополнительно `127.0.0.54:53` и `127.0.0.54:443`.

**Проверка сети прошла, модель не отвечает.** Прочитайте ошибку в Antigravity. Проверьте аккаунт, квоту и доступность сервиса. Успешный TLS не подтверждает доступ модели. Встроенные сетевые маршруты общедоступны и могут временно перестать работать.

**После обновления перестало работать.** Закройте Antigravity на 30 секунд или повторно нажмите «Включить». Незнакомая версия может потребовать обновления самого патчера.

**Откат отказался восстанавливать файл.** Файл обновлён, изменён или резервная копия повреждена. Не заменяйте новый файл старой копией вручную. Для возврата к чистой установке используйте штатную переустановку Antigravity.

## Где лежат настройки и копии

Windows: `%ProgramData%\PrivetAntigravity`. Кнопка «Файлы и журнал» открывает эту папку.

Linux: `${XDG_DATA_HOME:-~/.local/share}/PrivetAntigravity`.

В папке находятся `config.json`, `backups/records.json`, резервные копии и `service.log`. Журнал содержит технические ошибки подключения и пути файлов; содержимое чатов и пароли программа не записывает.

Дополнительные DNS можно добавить в список `resolvers` файла `config.json`: поддерживаются HTTPS DoH, `tls://имя-сервера` и IP-адрес DNS. После изменения перезапустите службу. Названия и адреса используемых внешних служб видны в этом файле и исходном коде.

## Полное удаление

Сначала выполните откат. В Windows затем удалите распакованный патчер и, если копии больше не нужны, папку `%ProgramData%\PrivetAntigravity`.

В Linux после отката удалите ярлыки и сам патчер:

```sh
rm -f ~/.local/bin/privetantigravity
rm -f ~/.local/share/applications/privetantigravity.desktop
rm -f ~/.local/share/applications/privetantigravity-launch.desktop
```

Папку данных с резервными копиями удаляйте отдельно, когда убедитесь, что они больше не нужны.
