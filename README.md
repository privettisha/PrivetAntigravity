# PrivetAntigravity

Патчер Antigravity для **Windows 10/11 x64** и **Arch Linux x86_64**. Без ключей, регистрации и активации. Находит установку, сохраняет оригиналы, применяет патч и включает локальную службу подключения.

**Первый выпуск — beta.** Проверены сборка Windows, запуск окна через Wine, Linux-клиент на копии файла, откат и соединения TLS. Установка службы на реальной Windows и ответ модели с аккаунтом пока не проверены.

## Скачать и запустить

Готовые файлы находятся в [Releases](https://github.com/privettisha/PrivetAntigravity/releases). Компилятор, Python и .NET для запуска не нужны.

**Windows**

1. Установите Antigravity, сохраните работу и полностью закройте его.
2. Скачайте `PrivetAntigravity-Windows-x64.zip` и распакуйте.
3. Откройте `PrivetAntigravity.exe`, подтвердите запрос администратора и нажмите **«Включить»**.
4. Нажмите **«Запустить Antigravity»**, войдите в Google и отправьте сообщение модели.

Если установка не найдена, нажмите **«Выбрать…»** и укажите `Antigravity.exe` или `agy.exe`.

**Arch Linux**

1. Скачайте `PrivetAntigravity-ArchLinux-x86_64.tar.gz` и распакуйте.
2. Откройте терминал в распакованной папке и выполните `./install.sh` от обычного пользователя.
3. Откройте **PrivetAntigravity** в меню приложений и выберите **1 — Включить**.
4. Запустите редактор пунктом **2** или ярлыком **PrivetAntigravity — запуск**.

Для записи в `/opt` помощник запросит права через `pkexec` или `sudo`. Служба работает через `systemd --user` после входа в сеанс. Подробности — в [инструкции](INSTRUCTION.md).

## Как работает

Программа меняет известные строки региональной проверки и настройки прокси в клиенте, сохраняя длину файлов. Для IDE поддерживается известный участок JavaScript с проверкой доступа. Совместимость зависит от версии Antigravity: незнакомые файлы и сигнатуры пропускаются.

Локальная служба принимает соединения клиента. Для трёх серверов Antigravity она получает адреса через шифрованный DNS и проверяет сертификат сервера. Адрес маршрута сохраняется на 45 секунд. Данные клиента проходят дальше в зашифрованном виде. Сертификаты в систему не устанавливаются.

В Windows точечные DNS-правила дополнительно направляют эти три имени в локальную службу, в том числе для клиентов, которые игнорируют переменную прокси. В Linux соединение настраивает ярлык запуска. Другие адреса через локальный прокси соединяются напрямую.

Раз в 30 секунд служба проверяет изменения файлов и повторяет патч после обновления. Если Antigravity держит файл открытым, закройте его и повторите включение.

## Откат

Нажмите **«Откатить»**; в Linux — пункт **5**. Программа выключит службу и восстановит сохранённые оригиналы. В Windows также удаляются её DNS-правила и переменная подключения. Если файл уже обновился или изменён, старая копия поверх него не записывается.

Резервные копии остаются на диске. Можно повторно включить патч.

## Проверка работы

Кнопка **«Проверить»** проверяет доступность соединения и сертификата TLS. Окончательная проверка — ответ модели в Antigravity. Подписка, квоты, доступ аккаунта и работа внешнего маршрута зависят от сервиса. Универсальная работа со всеми версиями и аккаунтами не гарантируется.

## Для разработки

Go 1.26 или новее. Основной код общий для двух систем; Windows-интерфейс использует штатные элементы Windows, Linux — меню терминала.

```sh
go test -race ./...
go vet ./...
./scripts/build.sh
```

Устройство проекта и результаты проверок описаны в [TECHNICAL.md](TECHNICAL.md) и [TESTING.md](TESTING.md).
